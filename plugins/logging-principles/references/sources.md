# Sources and attribution

The primary source is Nikita Sobolev, [Do not log](https://sobolevn.me/2020/03/do-not-log), published March 11, 2020.

The source-derived synthesis covers preventing invalid states, representing expected failures explicitly, separating important failure reporting from business-outcome monitoring, recognizing logging as a fallible side effect and maintained subsystem, improving retained context and severity, protecting sensitive information, and preserving useful startup or on-premise diagnostics. The synthesis is original and does not reproduce the article's prose, code, or screenshots. Illustrative libraries and programming styles in the article are not plugin requirements.

The decision procedure, workflow structure, report templates, evaluation design, and safeguards for failure semantics, required audit records, context minimization across destinations, environment coverage, and application-specific handling of diagnostic failures are extensions created for this plugin.

This plugin is not affiliated with or endorsed by Nikita Sobolev.
